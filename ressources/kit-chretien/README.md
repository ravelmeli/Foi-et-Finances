# Kit chrétien — autocollants réutilisables

Découpés une fois pour toutes depuis les planches K1 et K2 (`sources/`, prompts dans `ressources/prompts-kit-chretien.md`).
Pour un nouveau Short : copier les autocollants voulus dans `montage/<projet>/assets/stickers/`, puis les appeler par leur nom dans `build.py` (`sticker(S1, "baton-priere", ...)`).

| Autocollant | Usage |
| --- | --- |
| `livre-croix-ferme` | Bible fermée posée sur une table, à côté du budget |
| `livre-croix-ouvert` | Bible ouverte, station verset |
| `pupitre-parole` | la Parole sur son pupitre, avec croix vertes : station du choix, deux maîtres |
| `coeur-receptacle` | le cœur qui contient de l'argent : sujets d'attachement |
| `piedestal-pieces` | l'argent comme idole : face au pupitre de la Parole |
| `croix-verte` | croix seule (carte de fin, bulle de pensée, accent) |
| `baton-priere` | geste de foi : mains jointes, yeux fermés |
| `baton-lit-livre` | lecture de la Bible |
| `baton-pense` | réflexion, question |
| `baton-tiraille` | tiraillé entre deux maîtres |
| `baton-soucieux` | stress, difficulté (pas de symbole religieux autour) |
| `baton-serein` | paix, conclusion |

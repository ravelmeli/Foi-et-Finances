## ➤ Description de la video: 

Vous gagnez votre salaire, vous payez vos factures, et à la fin du mois vous vous demandez encore où est passé votre argent ? Dieu s'intéresse-t-il vraiment à la façon dont vous gérez vos finances ? La réponse de la Bible est claire : oui, non pas pour vous juger, mais pour vous libérer.

Dans cette vidéo, nous découvrons 7 principes bibliques simples pour devenir un meilleur gestionnaire de votre argent, avec des applications concrètes pour votre budget, votre épargne, vos dettes et votre générosité.

Dans cette vidéo, vous découvrirez :

* Pourquoi vous êtes gestionnaire, et non propriétaire, de votre argent ;  
* Pourquoi la fidélité commence dans les petites choses ;  
* Comment planifier avant de dépenser grâce à un budget simple ;  
* Comment préparer l'avenir comme la fourmi ;  
* Comment vous libérer progressivement de vos dettes ;  
* Comment donner avec joie, selon vos moyens ;  
* Le principe que presque tout le monde oublie : rendre des comptes chaque mois.

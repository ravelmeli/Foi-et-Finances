# Prompt Nano Banana — Short « Comment sortir progressivement du cycle des dettes » (planche optionnelle)

Même bloc de style et même bonhomme bâton que les autres vidéos. Aucun mot « Bible » dans le prompt.

## PLANCHE D1 — dettes (6 éléments)
Ordre de découpe : `boule-de-neige`, `dominos-dettes`, `trois-dettes`, `baton-conseiller`, `baton-soulage`, `escalier-sortie`.

Utilisation dans le montage :
- `trois-dettes` → étape 3 (la plus petite d'abord) ; `boule-de-neige` et `dominos-dettes` → étape 4 (la mensualité passe à la suivante) ;

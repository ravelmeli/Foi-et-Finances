Il est trois heures du matin et les mêmes chiffres tournent dans votre tête : le loyer, la facture, le découvert ? Le stress financier touche énormément de chrétiens sincères, et ce n'est pas un manque de foi.

Dans cette vidéo, nous découvrons ce que la Bible dit de l'inquiétude liée à l'argent, et un chemin à la fois spirituel et très concret pour retrouver la paix, même avant que tous les problèmes soient réglés.

Dans cette vidéo, vous découvrirez :

* Pourquoi le stress financier n'est pas un manque de foi ;  
* Comment la paix de Dieu peut garder votre cœur pendant les difficultés ;  
* Étape 1 : regarder la réalité en face et tout écrire ;  
* Étape 2 : remettre ce poids à Dieu de façon concrète ;  
* Étape 3 : choisir une seule action pour aujourd'hui ;  
* Étape 4 : ne pas porter ce poids seul ;  
* Un exemple concret pour faire le premier pas dès ce soir.

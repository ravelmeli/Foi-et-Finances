## ➤ Description de la video: 

On rêve de grandes finances… mais est-ce qu'on est fidèle dans les petites ? Découvre ce que dit Jésus en Luc 16:10 et quatre habitudes concrètes pour devenir fidèle avec ton argent.

Dans cette vidéo courte : les grandes finances se construisent dans les petits gestes. Quatre habitudes : 1) note chaque dépense, même 2 euros ; 2) paie à temps, même les petites factures ; 3) tiens tes promesses d'argent (un remboursement, un don décidé, un abonnement à résilier) ; 4) rends ce qui n'est pas à toi (la monnaie en trop, un objet emprunté, une somme avancée), l'habitude qu'on oublie le plus parce que personne ne nous regarde. Être fidèle, ce n'est pas être parfait : si tu as failli, corrige et recommence. Cette semaine, choisis une seule habitude et tiens-la sept jours.

"Celui qui est fidèle dans les moindres choses l'est aussi dans les grandes, et celui qui est injuste dans les moindres choses l'est aussi dans les grandes." — Luc 16:10 (Louis Segond 1910)
